## Overview

The mock backend stores all data in memory and starts empty on every page load. It's the default backend and requires no external services.

## Features

- Accepts a valid email and a password of six or more characters, and starts empty
- Holds invoice files in memory, too
- Full implementation of all `DatabaseAdapter` methods
- `__resetMockState()` for test isolation

## Usage

```ini
NEXT_PUBLIC_BACKEND=mock
```

No additional configuration needed — just run `pnpm dev`.

## Testing

The mock backend is used in all Vitest unit tests. Call `__resetMockState()` in `beforeEach` to ensure clean state between tests:

```typescript
import { __resetMockState } from "@/lib/backend/mock"

beforeEach(() => {
  __resetMockState()
})
```
