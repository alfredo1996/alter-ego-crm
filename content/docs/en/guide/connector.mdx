title: Connector
description: Connect an AI assistant over OAuth, an API key or stdio, and every tool it gets.

Alter Ego serves an MCP server, so an AI assistant can read and write the same data you see in the app. The app works fully without it: AI is optional.

## Connecting

Pick one of three ways.

- **OAuth**: add `/api/mcp` of your deployment as a remote connector in your assistant. It finds the sign-in and the scopes by itself (OAuth 2.1 with PKCE), you sign in as the owner and approve what it may do. **Settings, Data, Connectors** has **Disconnect All Connectors**, which takes access away from every connected app at once.
- **API key**: for a client that sends a fixed header. Create one in **Settings, Data, API Keys** with **Generate New API Key**: the key is shown once. Send it as `Authorization: Bearer <key>` to `/api/mcp`. A key carries both scopes. Revoking it cuts off anything using it at once, and cannot be undone.
- **stdio**: the assistant starts the server as a local process with `pnpm mcp:stdio`, with no sign-in: the process is the trust boundary, so there are no scopes. `ALTER_EGO_USER_ID` names whose data it serves and is required; the server exits at once without it. See the self-hosting guide in the repository for a client configuration.

## Scopes

OAuth grants two scopes, which the consent screen shows:

| Scope | What it allows |
|---|---|
| `data:read` | Issued and shown, but never checked: any valid token or API key can call the read tools |
| `data:write` | Required by every write tool; it does not include reading |

A token without `data:write` gets a clear refusal on a write tool, and a client can ask again for the missing scope. An API key carries both scopes. Which tools exist also depends on the plugins the deployment lists in `NEXT_PUBLIC_PLUGINS`: the tools of a plugin that is not listed are not offered. `get_quarters` is offered only when Accounting is on as well.

Some write tools **preview first**, as the tables below mark: called without `confirm` they change nothing and say exactly what would change, and the assistant is told to show that to you; only a second call with `confirm: true` writes.

## Tools

### Remote Connection Only

| Tool | Scope | What it does |
|---|---|---|
| `ping` | read | Checks that the connection works. Offered over OAuth and API key; the stdio server does not register it. |

### Personal Finance

| Tool | Scope | What it does |
|---|---|---|
| `list_categories` | read | The categories a transaction can be filed under. |
| `list_accounts` | read | Your personal accounts with their balance, split into assets and liabilities, and the net worth. |
| `list_tags` | read | The tags you have created. |
| `list_transactions` | read | Your personal transactions, newest first, with search and filters. |
| `get_spending` | read | Personal spending and income for a window of months, by category or by month. |
| `get_budget_status` | read | Every personal budget for its current period: spent, remaining and status. |
| `add_transaction` | write | Records a personal expense, income or transfer. |
| `update_transaction` | write | Corrects a personal transaction; balances follow; previews first. |
| `delete_transaction` | write | Deletes a personal transaction and restores the balance; previews first. |
| `create_account` | write | Opens a personal wallet, bank account, card or loan. |
| `archive_account` | write | Closes (archives) or reopens a personal account. |
