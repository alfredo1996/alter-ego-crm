## Overview

Alter Ego CRM is the management app of a small Italian SRL, built with Next.js 16, TypeScript, and Tailwind CSS v4: the sales pipeline, clients and contracts, time and the plan, invoices and their files, the cash book, the month-end close, solutions and rent. Each area is a module that a deployment can switch off. It uses a backend adapter pattern that lets you swap between the in-memory Mock backend and Firebase without changing feature code, and it serves an MCP connector for AI assistants. AI is always optional.

## Prerequisites

- **Node.js** 24+ (see `.nvmrc`)
- **pnpm** 10+
- (Optional) **Docker** to run the Firebase emulator locally

## Quick Start

```bash
# Clone the repository
git clone https://github.com/alfredo1996/alter-ego-crm.git
cd alter-ego-crm

# Install dependencies
pnpm install

# Start dev server (uses mock backend by default)
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) and sign in with any email and password: the mock backend accepts them and keeps its data in memory.

## Environment Variables

Create an `apps/web/.env.local` file:

```ini
# Backend: "mock" | "firebase"
NEXT_PUBLIC_BACKEND=mock

# Modules this deployment leaves out (crm, invoicing, books, solutions, rent)
NEXT_PUBLIC_DISABLED_MODULES=

# Firebase (only needed when NEXT_PUBLIC_BACKEND=firebase)
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=
```
