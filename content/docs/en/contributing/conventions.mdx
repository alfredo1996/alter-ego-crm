title: Conventions
description: Coding conventions and patterns used in Alter Ego
---

## File Naming

- **kebab-case** for all files: `use-clients.ts`, `client-card.tsx`
- Tests colocated in `__tests__/` directories: `apps/web/src/lib/__tests__/cash-book.test.ts`

## Exports

- **Named exports only** — no default exports except Next.js pages
- Components use `forwardRef` pattern with `displayName`

## Imports

Always use the `@/*` path alias:

```typescript
// Good
import { getBackend } from "@/lib/backend"

// Bad
import { getBackend } from "../../lib/backend"
```

## Styling

Use `cn()` for conditional Tailwind classes:

```typescript
import { cn } from "@alter-ego/ui/utils"

<div className={cn("p-4", isActive && "bg-primary/10")} />
```

## Validation

Zod schemas for all external data boundaries:

```typescript
import { createClientSchema } from "@/types/schemas"
```

## Backend Access

Never import Firebase directly:

```typescript
// Good
import { getBackend } from "@/lib/backend"

// Bad
import { collection, getDocs } from "firebase/firestore"
```

## Git Conventions

- **Commits**: Conventional Commits (`feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`)
- **Branches**: `feat/`, `fix/`, `refactor/` prefixes
- **PR titles**: Match commit convention

## Currency

Company money is euro. Format it with `eur` (whole euros) or `eurShort` (cents kept when there are any) from `@alter-ego/kernel/currency`; a component builds its own `Intl.NumberFormat` only for a form the kernel lacks:

```typescript
import { eur } from "@alter-ego/kernel/currency"

eur(1234.56) // "€1,235"
```

## Charts

All charts are pure SVG, with no external chart library.
