## Overview

Alter Ego is designed to deploy on Vercel with zero configuration beyond environment variables.

## Steps

1. Push your repository to GitHub
2. Import the project in [Vercel Dashboard](https://vercel.com/new)
3. Set environment variables for your chosen backend
4. Deploy

## Environment Variables

Set these in Vercel's project settings:

```ini
NEXT_PUBLIC_BACKEND=firebase

# Firebase
NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
```

## Build Settings

- **Framework**: Next.js (auto-detected)
- **Build command**: `pnpm build`
- **Install command**: `pnpm install`
- **Output directory**: `.next` (default)

## Notes

- Do **not** use `mock` backend in production
- Ensure your Firebase project has authentication configured
- Set up proper security rules before going live
