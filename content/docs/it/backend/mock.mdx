## Panoramica

Il backend mock memorizza tutti i dati in memoria e riparte vuoto a ogni caricamento della pagina. È il backend predefinito e non richiede servizi esterni.

## Funzionalità

- Accetta qualsiasi email e password e parte vuoto
- Tiene in memoria anche i file delle fatture
- Implementazione completa di tutti i metodi `DatabaseAdapter`
- `__resetMockState()` per l'isolamento dei test

## Utilizzo

```ini
NEXT_PUBLIC_BACKEND=mock
```

Nessuna configurazione aggiuntiva necessaria — basta eseguire `pnpm dev`.

## Test

Il backend mock è utilizzato in tutti i test unitari Vitest. Chiama `__resetMockState()` nel `beforeEach` per garantire uno stato pulito tra i test:

```typescript
import { getBackend } from "@/lib/backend"

beforeEach(() => {
  const backend = getBackend() as MockBackend
  backend.__resetMockState()
})
```
